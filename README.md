# HCM202 – Độc lập & Hội nhập

Trang React chuyển từ mẫu HTML MauHCM, dùng Vite.

## Chạy trên máy

Mở terminal tại D:\HCM202:

```sh
npm install
npm run dev
```

Mở địa chỉ mà terminal hiển thị (mặc định http://127.0.0.1:5173).

```sh
npm run build
npm run preview
```

Nút Thuyết trình bật toàn màn hình; phím Esc thoát toàn màn hình. Phím trái/phải chuyển phần khi không nhập liệu. Chơi đủ 10 tình huống hoặc chạm điều kiện kết thúc để lưu điểm. Bảng xếp hạng chỉ lưu tại trình duyệt hiện tại.

Nội dung chỉnh ở src/content.json; giao diện ở src/style.css; quy tắc mô phỏng ở src/game.js. Tổng nguồn lực luôn 100%, mỗi lượt tối đa 100 điểm. Tỷ lệ tham chiếu là quy ước trò chơi, không phải đáp án lịch sử. Dẫn nguồn kế thừa mẫu, cần đối chiếu với giáo trình của lớp. Tình huống bán dẫn & AI là tình huống vận dụng giả định. Ảnh tư liệu và phông Google cần Internet; khi mất mạng, trang vẫn sử dụng phông hệ thống, nội dung và trò chơi vẫn hoạt động.
